## 条目说明

- **V-09-001 DepthFlow**：DepthFlow：由图片与深度图生成 2.5D 视差镜头视频。 子分类：静态图片分层；照片空间化；多层景深。技术栈：Python。
- **V-09-002 3d-photo-inpainting**：3D Photography using Context-aware Layered Depth Inpainting（CVPR 2020 代码）。 子分类：照片空间化；摄像机推进；人物与背景分离。技术栈：Python;PyTorch。
- **V-09-003 3d-ken-burns**：3D Ken Burns Effect from a Single Image 的实现。 子分类：摄像机推进；照片空间化。技术栈：Python;PyTorch。
- **V-09-004 Depth-Anything-V2**：Depth Anything V2 可为图片生成深度图用于分层。 子分类：人物与背景分离；多层景深。技术栈：Python。
- **V-09-005 ml-depth-pro**：Depth Pro：单目度量深度估计（Apple 研究仓库，授权为自定义，需核查）。 子分类：照片空间化；多层景深。技术栈：Python。
- **V-09-006 rellax**：Rellax 视差，适合网页端视差原型。 子分类：前景运动；背景运动。技术栈：JavaScript。
- **V-09-007 maplibre-gl-js**：MapLibre 可做地图相机推拉（未验证）。 子分类：地图视差。技术栈：TypeScript。
