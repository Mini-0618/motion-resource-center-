## 条目说明

- **V-01-001 remotion**：Remotion：用 React 以编程方式制作视频，可参数化文字动画并渲染 MP4。 子分类：逐字出现；逐词强调；字幕高亮；标题冲击。技术栈：TypeScript;React;FFmpeg。
- **V-01-002 template-tiktok**：用 Whisper.cpp 生成 TikTok 风格字幕的 Remotion 模板（仓库描述）。 子分类：字幕高亮；逐词强调。技术栈：TypeScript;Remotion;Whisper.cpp。
- **V-01-003 template-code-hike**：Remotion 官方“代码片段动画”模板（仓库描述）。 子分类：信息密集型文字动画。技术栈：TypeScript;Remotion。
- **V-01-004 remocn**：面向 Remotion 的动画、转场、背景与场景组件集（仓库描述）。 子分类：标题冲击；文字遮罩；多层排版。技术栈：TypeScript;Remotion。
- **V-01-005 remotion-templates**：免费 Remotion 特效与动画模板集（仓库描述）。 子分类：文字位移；标题冲击。技术栈：TypeScript;Remotion。
- **V-01-006 motion-canvas**：Motion Canvas：用 TypeScript 生成器编写矢量动画并配可视化编辑器。 子分类：文字位移；字符重组。技术栈：TypeScript。
- **V-01-007 revideo**：Revideo：用代码创建视频的框架（仓库描述 Create Videos with Code）。 子分类：逐字出现；文字位移。技术栈：TypeScript。
- **V-01-008 GSAP**：GSAP（GreenSock）：JavaScript 动画库，支持时间线与精细缓动。 子分类：文字拆分；文字位移；文字旋转。技术栈：JavaScript。
- **V-01-009 anime**：Anime.js：轻量 JS 动画引擎。 子分类：文字位移；逐字出现。技术栈：JavaScript。
- **V-01-010 typed.js**：Typed.js：打字机效果库。 子分类：逐字出现。技术栈：JavaScript。
- **V-01-011 source-han-sans**：思源黑体（Source Han Sans）字体源码仓库，覆盖中日韩字符。 子分类：必须支持中文字体。技术栈：字体工程（Python 构建脚本）。
- **V-01-012 LxgwWenKai**：霞鹜文楷中文开源字体项目。 子分类：必须支持中文字体。技术栈：字体工程。
