## 条目说明

- **V-12-001 template-three**：Remotion + React Three Fiber 最小模板（仓库描述）。 子分类：三维模型展示；3D 文字。技术栈：TypeScript;Remotion;R3F。
- **V-12-002 three.js**：three.js 官方仓库。 子分类：三维模型展示；三维场景；三维灯光；材质变化。技术栈：JavaScript。
- **V-12-003 react-three-fiber**：React Three Fiber。 子分类：三维场景；摄像机轨迹。技术栈：TypeScript。
- **V-12-004 drei**：drei 提供 3D 文字等辅助。 子分类：3D 文字；三维场景。技术栈：TypeScript。
- **V-12-005 model-viewer**：model-viewer：网页显示交互式 3D 模型与 AR（仓库描述）。 子分类：三维模型展示；资产导入导出。技术栈：TypeScript。
- **V-12-006 Babylon.js**：Babylon.js：开放的 JS 游戏与渲染引擎（仓库描述）。 子分类：三维场景；三维灯光；材质变化。技术栈：TypeScript。
- **V-12-007 glTF-Blender-IO**：Khronos 的 Blender glTF 导入导出插件。 子分类：资产导入导出；Blender 自动渲染。技术栈：Python。
- **V-12-008 mcp-for-blender**：mcp-for-blender（原 blender-mcp）：让 AI 通过 MCP 控制 Blender（据其定位，需核查安全性）。 子分类：Blender 自动渲染；程序化建模。技术栈：Python。
- **V-12-009 BlenderProc**：BlenderProc：基于 Blender 的程序化渲染管线。 子分类：Blender 自动渲染；程序化建模。技术栈：Python。
- **V-12-010 gltfjsx**：gltfjsx：把 GLTF 转为 JSX 组件（仓库描述）。 子分类：资产导入导出；可编辑场景工程。技术栈：JavaScript。
- **V-12-011 cesium**：CesiumJS：3D 地球与地图库。 子分类：三维地图。技术栈：JavaScript;WebGL。
- **V-12-012 blender**：Blender 官方镜像。 子分类：Blender 自动渲染；三维场景；程序化建模。技术栈：C++;Python。
