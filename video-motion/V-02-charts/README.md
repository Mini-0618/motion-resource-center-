## 条目说明

- **V-02-001 manim**：Manim 社区版：用 Python 编程制作解释型数学/数据动画。 子分类：柱状图；折线图；时间序列。技术栈：Python;FFmpeg;Cairo。
- **V-02-002 manim**：3Blue1Brown 作者的 Manim 版本。 子分类：折线图；柱状图。技术栈：Python;OpenGL。
- **V-02-003 bar_chart_race**：Python 库：制作动态排行榜（bar chart race）动画（仓库作者近期更新较少）。 子分类：动态排行榜；排名变化。技术栈：Python;matplotlib。
- **V-02-004 vega-lite**：Vega-Lite：声明式交互图形语法。 子分类：柱状图；折线图；散点图。技术栈：TypeScript;JSON 规范。
- **V-02-005 plotly.js**：plotly.js：开源 JS 图表库。 子分类：折线图；散点图；面积图；饼图。技术栈：JavaScript;WebGL;SVG。
- **V-02-006 deck.gl**：deck.gl：基于 WebGL 的大规模地理空间数据可视化框架。 子分类：地图数据；全球数据对比。技术栈：TypeScript;WebGL。
- **V-02-007 template-audiogram**：Remotion 播客片段（audiogram）模板（仓库描述）。 子分类：数字计数。技术栈：TypeScript;Remotion。
- **V-02-008 vega**：Vega：可视化语法，JSON 描述图表。 子分类：散点图；折线图；时间序列。技术栈：JavaScript。
- **V-02-009 plotly.py**：Plotly Python 图表库（本机可导出静态图/动画帧，未验证）。 子分类：折线图；散点图；饼图；地图数据。技术栈：Python。
- **V-02-010 gganimate**：gganimate：R 的动画图形语法。 子分类：时间序列；排名变化。技术栈：R。
- **V-02-011 maplibre-gl-js**：MapLibre GL JS：浏览器矢量地图。 子分类：地图数据；全球数据对比。技术栈：TypeScript;WebGL。
- **V-02-012 pyecharts**：pyecharts：用 Python 生成 ECharts 图表。 子分类：柱状图；折线图；饼图；地图数据。技术栈：Python。
- **V-02-013 matplotlib**：Matplotlib：Python 绘图库，含动画模块（据其功能）。 子分类：折线图；散点图；面积图。技术栈：Python。
- **V-02-014 videos**：3Blue1Brown 视频制作所用代码仓库，供参考复现（授权与素材限制需单独核查）。 子分类：研究实验结果；数据不确定性可视化。技术栈：Python;Manim。
- **V-02-015 echarts**：ECharts 同样可用于视频图表渲染（需截帧/录屏，未验证）。 子分类：柱状图；折线图；饼图；地图数据；时间序列。技术栈：JavaScript。
- **V-02-016 d3**：D3 可编写动态排行榜等定制动画。 子分类：排名变化；动态排行榜；时间序列。技术栈：JavaScript。
- **V-02-017 d3-sankey**：d3-sankey：桑基图布局。 子分类：市场份额变化；财务数据。技术栈：JavaScript。
