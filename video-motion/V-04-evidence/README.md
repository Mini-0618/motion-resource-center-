## 条目说明

- **V-04-001 rough-notation**：Rough Notation：给网页元素添加手绘风标注（下划线、圈出、高亮）的小库。 子分类：论文重点标记；原文引用。技术栈：TypeScript。
- **V-04-002 playwright**：Playwright：浏览器自动化，可截图、录制视频（用于获取真实网页证据画面）。 子分类：网页滚动；网页局部放大；截图拼接。技术栈：TypeScript。
- **V-04-003 puppeteer**：Puppeteer：Chrome 自动化库，可截图。 子分类：网页滚动；截图拼接。技术栈：TypeScript。
- **V-04-004 pdf.js**：PDF.js：浏览器 PDF 阅读器，可在网页渲染论文页并定位文本。 子分类：论文页面展示；报告关键段落；数据表定位。技术栈：JavaScript。
- **V-04-005 shot-scraper**：shot-scraper：命令行网页截图、录制演示视频、用 JS 抓取（仓库描述）。 子分类：网页滚动；来源日期标记；截图拼接。技术栈：Python。
- **V-04-006 client**：Hypothesis 网页标注客户端（许可证见风险标记）。 子分类：论文重点标记；原文引用。技术栈：JavaScript。
- **V-04-007 annotorious**：Annotorious：图片标注库。 子分类：局部高亮；数据表定位。技术栈：TypeScript。
