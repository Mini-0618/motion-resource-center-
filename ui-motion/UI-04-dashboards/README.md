## 条目说明

- **UI-04-001 echarts**：Apache ECharts：功能完整的开源可视化图表库，支持动画与动态数据更新。 子分类：折线图生长；柱状图增长；饼图与环形图；雷达图；热力图；桑基图。技术栈：JavaScript/TypeScript;Canvas;SVG。
- **UI-04-002 echarts-examples**：ECharts 官方示例集合（含各类图表示例源码）。 子分类：折线图生长；柱状图增长；饼图与环形图。技术栈：TypeScript;ECharts。
- **UI-04-003 d3**：D3：数据驱动文档的可视化基础库，支持数据绑定与过渡动画。 子分类：数据筛选转场；时间序列；桑基图。技术栈：JavaScript。
- **UI-04-004 plot**：Observable Plot：基于图形语法的 JS 数据可视化库。 子分类：时间序列；多指标对比。技术栈：JavaScript。
- **UI-04-005 Chart.js**：Chart.js：基于 Canvas 的简洁图表库，内置动画。 子分类：折线图生长；柱状图增长；饼图与环形图；雷达图。技术栈：JavaScript/TypeScript;Canvas。
- **UI-04-006 recharts**：Recharts：基于 React 与 D3 子模块的图表库。 子分类：折线图生长；柱状图增长；饼图与环形图。技术栈：React;TypeScript;SVG。
- **UI-04-007 visx**：visx：Airbnb 的 React 低层可视化原语集合。 子分类：时间序列；多指标对比。技术栈：React;TypeScript;D3。
- **UI-04-008 nivo**：nivo：基于 React 与 D3 的丰富图表组件库，含多种图表类型。 子分类：热力图；桑基图；雷达图；饼图与环形图。技术栈：React;D3。
- **UI-04-009 tremor**：Tremor：用于搭建仪表盘的 React 复制粘贴组件（仓库描述）。 子分类：KPI 数字卡片；多指标对比。技术栈：React;Tailwind CSS;Radix UI。
- **UI-04-010 number-flow**：NumberFlow：数字变化的平滑过渡动画组件。 子分类：实时数字滚动；KPI 数字卡片。技术栈：TypeScript;Web Components。
- **UI-04-011 uPlot**：uPlot：快速、占用小的时间序列图表库。 子分类：实时监控曲线；时间序列。技术栈：JavaScript;Canvas。
- **UI-04-012 apexcharts.js**：ApexCharts：现代交互式 SVG 图表库。 子分类：折线图生长；柱状图增长；饼图与环形图；雷达图；热力图。技术栈：JavaScript;SVG。
- **UI-04-013 G2**：AntV G2：基于图形语法的可视化库。 子分类：折线图生长；柱状图增长；多指标对比。技术栈：TypeScript;Canvas/SVG。
- **UI-04-014 gridstack.js**：Gridstack：可拖拽、可调整大小的仪表盘网格布局库。 子分类：数据卡片重排。技术栈：TypeScript。
- **UI-04-015 perspective**：Perspective：面向大规模/流式数据的可视化与分析组件。 子分类：实时监控曲线；热力图；时间序列。技术栈：Rust;WebAssembly;JavaScript。
- **UI-04-016 grafana**：Grafana：开源监控与可观测性平台，可搭建仪表盘。 子分类：实时监控曲线；AI 调用量监控；Token 成本监控。技术栈：TypeScript;Go。
- **UI-04-017 superset**：Apache Superset：开源数据探索与仪表盘平台。 子分类：数据筛选转场；图表钻取；时间序列。技术栈：Python;TypeScript。
- **UI-04-018 langfuse**：Langfuse：开源 LLM 工程平台，含追踪、评测与指标面板（据其定位）。 子分类：AI 调用量监控；Token 成本监控；任务成功率。技术栈：TypeScript。
- **UI-04-019 free-react-tailwind-admin-dashboard**：免费 React + Tailwind 管理仪表盘模板（仓库描述）。 子分类：KPI 数字卡片；折线图生长；柱状图增长。技术栈：React;Tailwind CSS。
- **UI-04-020 dashboardblocks**：shadcn/ui 的仪表盘区块：KPI、图表、表格与完整仪表盘（仓库描述）。 子分类：KPI 数字卡片；图表钻取。技术栈：React;TypeScript;shadcn CLI。
- **UI-04-021 microcharts**：React 迷你图（word-sized）组件库，含 106 种图表类型（仓库描述）。 子分类：多指标对比；KPI 数字卡片。技术栈：React;TypeScript。
- **UI-04-022 chartbrew**：开源报表平台，可由 API/SQL/NoSQL 构建实时仪表盘（仓库描述）。 子分类：视频运营数据面板；数据筛选转场。技术栈：JavaScript;Node.js。
