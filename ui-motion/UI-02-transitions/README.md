## 条目说明

- **UI-02-001 next-view-transitions**：在 Next.js App Router 中使用 CSS View Transitions API（仓库描述）。 子分类：路由转场；共享元素转场；页面切换。技术栈：TypeScript;Next.js。
- **UI-02-002 barba**：Barba.js：为多页站点提供平滑页面转场。 子分类：页面切换；路由转场。技术栈：JavaScript。
- **UI-02-003 swup**：swup：多页站点的页面过渡库。 子分类：页面切换；路由转场。技术栈：JavaScript。
- **UI-02-004 locomotive-scroll**：Locomotive Scroll：平滑滚动与视差效果库。 子分类：视差滚动；页面滚动触发。技术栈：TypeScript。
- **UI-02-005 lenis**：Lenis：轻量平滑滚动库，常与滚动动画库配合。 子分类：页面滚动触发；视差滚动。技术栈：TypeScript。
- **UI-02-006 aos**：AOS：滚动进入时的动画库（作者仓库近两年更新较少）。 子分类：页面内容渐进显示；页面滚动触发。技术栈：JavaScript;CSS。
- **UI-02-007 rellax**：Rellax：轻量纯 JS 视差滚动库。 子分类：视差滚动。技术栈：JavaScript。
- **UI-02-008 vaul**：Vaul：React 抽屉（底部面板）组件。 子分类：弹窗与抽屉。技术栈：TypeScript;React。
- **UI-02-009 tldraw**：tldraw：React 无限画布 SDK（许可证为自定义，见风险标记）。 子分类：无限画布缩放。技术栈：TypeScript;React。
- **UI-02-010 motion**：Motion 的布局动画能力可用于共享元素与布局重排（据其定位，未逐项验证）。 子分类：共享元素转场；卡片展开为详情页；工作区布局重排。技术栈：TypeScript;React。
