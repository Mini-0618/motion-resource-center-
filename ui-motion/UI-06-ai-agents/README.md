## 条目说明

- **UI-06-001 ai**：Vercel AI SDK：TypeScript AI 应用工具包，含流式输出与工具调用。 子分类：流式文本；工具调用；消息流。技术栈：TypeScript。
- **UI-06-002 assistant-ui**：assistant-ui：用于 AI 聊天的 TypeScript/React 库（仓库描述）。 子分类：消息流；流式文本；工具调用。技术栈：React;TypeScript。
- **UI-06-003 CopilotKit**：CopilotKit：把智能体与副驾驶能力接入应用前端的框架。 子分类：人工审批；工具调用；多 Agent 协作。技术栈：TypeScript;React。
- **UI-06-004 ag-ui**：AG-UI：智能体与用户交互协议，把智能体接入前端（仓库描述）。 子分类：消息流；智能体工作状态；工具调用。技术栈：TypeScript;协议。
- **UI-06-005 ai-elements**：基于 shadcn/ui 的 AI 原生应用组件库与注册表（仓库描述）。 子分类：消息流；流式文本；工具调用。技术栈：TypeScript;shadcn/ui。
- **UI-06-006 streamdown**：react-markdown 的直接替代品，为 AI 流式输出设计（仓库描述）。 子分类：流式文本。技术栈：TypeScript;React。
- **UI-06-007 thinking-orbs**：面向 AI/智能体 UI 的点阵“思考球”加载指示器，9 种类型两种尺寸（仓库描述）。 子分类：智能体思考状态；节点等待。技术栈：TypeScript;React。
- **UI-06-008 gaia-ui**：构建 AI Agent 的 UI 组件库（仓库描述）。 子分类：智能体工作状态；工具调用。技术栈：TypeScript;React。
- **UI-06-009 xyflow**：xyflow（React Flow/Svelte Flow）：构建节点式编辑器与工作流图的库。 子分类：工作流节点运行；节点等待；节点失败；任务派发。技术栈：TypeScript;React/Svelte。
- **UI-06-010 langflow**：Langflow：可视化构建智能体与工作流的平台。 子分类：工作流节点运行；多 Agent 协作。技术栈：Python;TypeScript。
- **UI-06-011 n8n**：n8n：可视化工作流自动化平台，具备 AI 能力。 子分类：工作流节点运行；自动重试；节点失败。技术栈：TypeScript。
- **UI-06-012 open-webui**：Open WebUI：自托管 AI 聊天界面。 子分类：消息流；流式文本；模型切换；多模型对比。技术栈：Svelte;Python。
- **UI-06-013 NextChat**：NextChat：跨平台多模型聊天应用。 子分类：消息流；流式文本；模型切换。技术栈：TypeScript;Next.js。
- **UI-06-014 Flowise**：Flowise：可视化构建 AI 智能体与流程的工具（本仓库已被作者归档）。 子分类：工作流节点运行；多 Agent 协作。技术栈：TypeScript;Node.js。
