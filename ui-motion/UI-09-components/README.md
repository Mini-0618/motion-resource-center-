## 条目说明

- **UI-09-001 shiki**：Shiki：基于 TextMate 语法的代码高亮库。 子分类：代码展示组件。技术栈：TypeScript。
- **UI-09-002 shiki-magic-move**：Shiki Magic Move：代码块之间的平滑过渡动画（仓库已归档）。 子分类：代码展示组件；Markdown 内容转场。技术栈：TypeScript。
- **UI-09-003 xterm.js**：xterm.js：网页终端组件。 子分类：终端动画。技术栈：TypeScript。
- **UI-09-004 mermaid**：Mermaid：用文本生成流程图/时序图等的 JS 库。 子分类：可视化流程图。技术栈：TypeScript。
- **UI-09-005 table**：TanStack Table：无头表格库（动画需自行实现）。 子分类：数据表格动画。技术栈：TypeScript。
- **UI-09-006 react-window**：react-window：React 虚拟化长列表。 子分类：资源库浏览器；列表虚拟滚动。技术栈：TypeScript;React。
- **UI-09-007 masonry**：Masonry：级联网格（瀑布流）布局插件。 子分类：图片瀑布流。技术栈：JavaScript。
- **UI-09-008 TimelineJS3**：TimelineJS：交互式时间线。 子分类：时间线组件。技术栈：JavaScript。
- **UI-09-009 xyflow**：xyflow：节点式流程图库，适合可视化流程。 子分类：可视化流程图。技术栈：TypeScript。
- **UI-09-010 streamdown**：流式 Markdown 渲染。 子分类：Markdown 内容转场。技术栈：TypeScript。
