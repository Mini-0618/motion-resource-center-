## 条目说明

- **UI-05-001 three.js**：three.js：JavaScript 3D 库，官方仓库含大量 examples。 子分类：3D 卡片；摄像机环绕；粒子云。技术栈：JavaScript;WebGL/WebGPU。
- **UI-05-002 react-three-fiber**：React Three Fiber：three.js 的 React 渲染器。 子分类：三维节点网络；摄像机环绕。技术栈：TypeScript;React;three.js。
- **UI-05-003 drei**：drei：R3F 的实用辅助组件集合。 子分类：场景景深；节点高亮。技术栈：TypeScript;React;three.js。
- **UI-05-004 3d-force-graph**：3D 力导向图组件，基于 three.js/WebGL（据仓库名与定位）。 子分类：三维节点网络；知识图谱；节点高亮；摄像机环绕。技术栈：JavaScript;three.js;WebGL。
- **UI-05-005 react-force-graph**：react-force-graph：React 的 2D/3D/VR 力导向图组件。 子分类：三维节点网络；多智能体关系网络；任务依赖网络。技术栈：JavaScript;React;three.js。
- **UI-05-006 globe.gl**：globe.gl：基于 three.js 的 3D 地球数据可视化。 子分类：3D 数据球体。技术栈：JavaScript;three.js。
- **UI-05-007 uikit**：pmndrs/uikit：three.js/R3F 中的三维用户界面组件。 子分类：3D 卡片；3D 旋转面板；空间导航。技术栈：TypeScript;three.js;R3F。
- **UI-05-008 G6**：AntV G6：图可视化引擎（主要为二维，3D 需另配）。 子分类：知识图谱（二维）；节点展开详情；节点高亮。技术栈：TypeScript;Canvas/WebGL。
- **UI-05-009 vis-network**：vis-network：二维网络图可视化，含物理布局动画。 子分类：知识图谱（二维）；节点高亮。技术栈：JavaScript;Canvas。
- **UI-05-010 cytoscape.js**：Cytoscape.js：图论/网络分析与可视化库（二维）。 子分类：知识图谱（二维）；任务依赖网络；文件关系可视化。技术栈：JavaScript。
- **UI-05-011 postprocessing**：postprocessing：three.js 后处理效果库。 子分类：场景景深。技术栈：TypeScript;three.js。
