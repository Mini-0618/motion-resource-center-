## 条目说明

- **UI-03-001 liquid-glass-react**：React 组件，仿 iOS 风格“液态玻璃”折射与模糊效果（仓库描述：Apple's Liquid Glass effect for React）。 子分类：玻璃折射模拟；玻璃卡片悬浮；玻璃质感随鼠标位置变化。技术栈：React;CSS;SVG filter。
- **UI-03-002 liquid-dom**：面向 Web 的“液态玻璃”效果库（仓库描述：Liquid Glass for the Web）。 子分类：玻璃折射模拟；真实背景模糊。技术栈：TypeScript;Web。
- **UI-03-003 liquid-glass-js**：苹果风格玻璃效果 JS 库（仓库描述：Liquid Glass UI - Apple-Inspired Glass Effects Library）。 子分类：玻璃折射模拟；玻璃边缘高光。技术栈：JavaScript。
- **UI-03-004 liquidGL**：基于 WebGL/WebGPU 的网页“液态玻璃”效果（仓库描述：liquidGL – Liquid Glass For The Web）。 子分类：玻璃折射模拟；动态模糊背景。技术栈：JavaScript;WebGL/WebGPU。
- **UI-03-005 liquidglass**：为任意 HTML 元素添加玻璃折射、模糊、色散和光照效果的 WebGL 库（据仓库描述）。 子分类：玻璃折射模拟；玻璃边缘高光。技术栈：TypeScript;WebGL。
- **UI-03-006 liquid-glass**：iOS 26 风格液态玻璃效果的交互式网页演示（仓库描述）。 子分类：玻璃折射模拟。技术栈：HTML;SVG filter;WebGL。
- **UI-03-007 liquid-glass**：仅用 CSS 与 SVG 滤镜复刻 iOS 26 液态玻璃，含玻璃容器、文字、按钮组件（据仓库描述）。 子分类：玻璃折射模拟；玻璃卡片悬浮。技术栈：Astro;CSS;SVG filter。
- **UI-03-008 vaso**：React 的液态玻璃效果组件（仓库描述：Liquid Glass effect for React）。 子分类：玻璃折射模拟。技术栈：React;TypeScript。
- **UI-03-009 liquid-glass-vue**：Vue 3 的 iOS 26 液态玻璃效果组件（仓库描述）。 子分类：玻璃折射模拟。技术栈：Vue 3;TypeScript。
- **UI-03-010 plasma-ui**：React 液态玻璃组件库，主题含 metaballs、shaders（据仓库主题标签）。 子分类：多层玻璃叠加；动态噪声纹理。技术栈：React;TypeScript;Shader。
- **UI-03-011 glass-ui**：基于毛玻璃设计规范的 CSS UI 库（仓库描述）。 子分类：半透明玻璃面板；玻璃导航栏；玻璃弹窗。技术栈：CSS;HTML;JavaScript。
- **UI-03-012 css.glass**：毛玻璃 CSS 生成器（css.glass）的源码（仓库描述）。 子分类：半透明玻璃面板；真实背景模糊。技术栈：Vue;Nuxt。
- **UI-03-013 liquid-glass-effect-macos**：macOS 风格液态玻璃效果的 HTML 演示（仓库描述仅“Demo here”）。 子分类：玻璃折射模拟。技术栈：HTML。
- **UI-03-014 dashdot**：带毛玻璃主题的服务器监控仪表盘（仓库主题含 glassmorphism）。 子分类：半透明玻璃面板；深浅主题过渡。技术栈：TypeScript;React;Node.js。
- **UI-03-015 Cloudy**：Kotlin Multiplatform 的模糊与液态玻璃效果库，GPU 加速并为旧设备提供 CPU 回退（据仓库描述）。 子分类：真实背景模糊；低性能设备的降级效果。技术栈：Kotlin;Jetpack Compose。
- **UI-03-016 AndroidLiquidGlass**：Compose Multiplatform 液态玻璃效果（仓库描述）。 子分类：玻璃折射模拟。技术栈：Kotlin;Compose。
- **UI-03-017 liquid_glass_widgets**：Flutter 玻璃组件库，实现 iOS 26/27 液态玻璃设计语言，含基于着色器的模糊（据仓库描述）。 子分类：玻璃导航栏；玻璃工具栏；玻璃弹窗。技术栈：Dart;Flutter。
- **UI-03-018 liquid-glass**：React Native 的液态玻璃封装（仓库描述：Liquid Glass in React Native）。 子分类：玻璃折射模拟。技术栈：Objective-C++;React Native。
- **UI-03-019 LiquidGlassReference**：iOS 26 Liquid Glass 的 Swift/SwiftUI 参考文档仓库（非动效库，仅作设计参考）。 子分类：玻璃折射模拟。技术栈：Swift;SwiftUI。
