# 视频蒸馏知识库

- 智能体：技能 `video_distill`（~/workspace/custom-skills/video_distill/），提示词为《AI 视频蒸馏与制作知识库 · 总控指令 V1.2》全文。
- `视频/<视频ID或标题>/`：每条参考视频一个目录，存七份交付文件（video-analysis.md、shots.csv、audio-timeline.csv、effects.json、workflow.md、assets-manifest.csv、verification.md）。
