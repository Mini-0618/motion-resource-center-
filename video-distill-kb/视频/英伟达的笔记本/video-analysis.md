## 三、核心观点：主张／片中证据／已核实事实

**视频提出的主张**（分析者概括，非原文）：
1. RTX Spark 的价值不在笔记本形态，而在统一大内存使本地 AI（智能体、大模型、实时视觉）第一次在笔记本上实用。
2. 本地化的核心优势是隐私（素材不出本机）与零边际费用，其次才是速度；现阶段本地 Agent 能做流程，不能替代创作。

**片中展示的证据**：跑分图（双锚对照）、达芬奇 MCP 本地剪辑实验全程、游戏帧率与兼容名单、DLSS5 同屏对比、云台口令跟踪的本地/云端响应对比、视频生成计时与省钱换算。

## 八、入选方法（每条：六问＋四道门＋反证）

### M01 厂商口号当考题（叙事与文案）→ 新建 NAR-2026-019

1. **看到了什么**：P1 借黄仁勋「重新发明的电脑」立题并以问题句收尾；P2–P7 逐项验收（性能、剪辑、游戏、本地模型、生成成本）；P7 给验收结论——硬件形态没变，成立的是贴纸背后的生态（大显存＋本地 AI），结论带保留（帧可见贴纸特写为落点）。
2. **可能起什么作用**（已推断）：厂商口号自带流量与争议，把它当考题等于借对方的势能做自己的结构；逐项验收使结论无论正反都显得是测出来的而非站队。其他合理解释：可能只是蹭发布会热度——排除依据：口号在结尾被正式回收并给出限定结论，且每一项测试都对应口号的一个侧面（算力、形态、生态），是结构而非标题党。
3. **适用范围**：某类结构规律——有厂商大口号可借的评测/解读片。
4. **换题材要保留什么**：口号必须原样引用并注明出处、验收项必须覆盖口号的每个暗示、结论必须给限定（哪部分成立、哪部分不成立）。失效情形：口号本身无人知晓时借不到势；验收项与口号暗示对不上时结构散架。
5. **怎样重做**：发布会/官宣中挑最大的一句口号→拆成 3–5 个可测侧面→逐项实测→结尾用一个最小物件或一句限定句交付验收结论→趋势判断只给一句。
6. **怎样知道做对了**：评论区争论的是口号成不成立（而非产品参数细节）；标题与口号的关联被观众自发复述。
- 四道门：有证据✓（立题、验收、回收三点齐备）；有失效情形✓；有迁移例子✓（如拿「AI 手机元年」当考题逐项验收）；不重复✓（与 NAR-2026-001 判词先行的区别：那是自家判词先行，本条是借对方判词立题、我方只做验收）。

### M02 首组合实验（叙事与文案）→ 新建 NAR-2026-020

1. **看到了什么**：P3 把两个刚出现的新能力首次组合——达芬奇新加的 MCP 支持×本地视觉模型，经 Agent 操控专业软件完成导入、整理、上时间线、导出预览，全程不联网；旁白明标「替你做了一个独特的实验」。P6 的云台口令跟踪是同法的第二次使用（视觉模型×相机云台）。
2. **可能起什么作用**（已推断）：单能力评测到处都是，组合实验产出的是别家没有的画面与结论（「本地 Agent 能干多少活」），是评测频道最便宜的差异化。其他合理解释：可能只是赶新功能的常规尝试——排除依据：实验设计明确冲着「一切都是本地的」这一组合前提，且结论（能做流程、不能成片）只有组合实验才能得出。
3. **适用范围**：某类段落规律——新能力密集发布期的评测与科技内容。
4. **换题材要保留什么**：组合的两端都必须新、组合必须产出单一能力测不出的问题（如全链路本地化）、结论必须报边界。失效情形：组合只是把两个功能并排展示、无新问题产生时是拼盘不是实验。
5. **怎样重做**：列当期新能力清单→两两配对找「没人试过的组合」→写出该组合独有的问题→实测并记录失败点→结论分两句：能做到的、做不到的。
6. **怎样知道做对了**：同题材其他评测未出现该实验；评论区出现「就你家测了这个」类反馈。
- 四道门：有证据✓（两处实验互证）；有失效情形✓；有迁移例子✓（如本地模型×剪辑软件、生成视频×直播导播）；不重复✓。

### M03 优势换算成钱与秒（叙事与文案）→ 新建 NAR-2026-021

1. **看到了什么**：抽象优势一律换算——视频生成：23 分钟/条→每天 3–4 小时→约省一两百元/天（P7）；本地部署：费用为零＋隐私不出本机（P3/P6）；响应速度：不给毫秒数，给「跟上黑衣人」的同题实景对比（P6）。
2. **可能起什么作用**（已推断）：「强」「快」「省」都是形容词，换算成元/天与跟丢/跟上，观众才能拿自己的账本验算，种草或祛魅当场完成。其他合理解释：可能只是报价习惯——排除依据：换算在三处不同优势上重复出现且都给出完整换算链（单价×频次＝日账），是稳定的文案规则。
3. **适用范围**：跨全片规则——一切带有效益主张的产品与工具内容。
4. **换题材要保留什么**：换算链必须完整（单次量×使用频次＝日/月账）、频次假设必须说出口、不许只给最有利的单一数字。失效情形：目标观众不为该成本付费（如企业报销场景）时钱账失效，应换算成时间或风险。
5. **怎样重做**：列优势清单→每条找可测单价（元/分钟/token）→乘上明示的日频次→给出日账或月账→速度类优势改用同题实景对比呈现。
6. **怎样知道做对了**：评论区有人按自己的频次重算并贴出数字；观众复述时先说钱数再说参数。
- 四道门：有证据✓（三处换算互证）；有失效情形✓；有迁移例子✓（如把会员费换算成每条视频成本）；不重复✓（与 NAR-2026-013 链条推演的区别：那是机制传导，本条是效益定价）。
