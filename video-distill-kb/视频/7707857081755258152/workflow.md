# 制作流程复原 — 太学TAIXUE 李丰《机器人的投资逻辑》（抖音 ID 7707857081755258152）

> 复原口径：由成片反推（已推断），非片方披露。证据见 video-analysis.md 与本目录其余文件；本片只做分析，未做实现与迁移验证。

## 流程总览

选题（投资人讲产业）→ 现场多机位录制 → 粗剪与机位轮换 → 冷开场摘要段前置组装 → 字幕与包装 → 片尾字卡与发布 → 数据登记。

## 逐步复原

1. **选题与讲者**：讲者为一线早期投资机构合伙人，选题取其正在布局的赛道（机器人）——讲者身份本身就是内容资格；讲稿结构（结论—例链—挑战—收尾）在录制前应已成形，冷开场的三句结论与正文总论逐字对应，说明摘要段与正文同出一稿。
2. **现场录制**：太学舞台（圆形光盘、TAIXUE 发光字、黑场）多机位同录：中景主机位、近景机位、全景机位、极远机位与一只背影机位（S028）；讲者耳麦收声，无提词器痕迹（视线与手势为自然讲述态）。
3. **粗剪与机位轮换**：98 个镜头由固定机位跳切轮换构成（中景 44、全景 40、极远 9、近景 3、背影 1、片尾过渡 1），镜头中位时长 6.70 秒；无运镜、无空镜、无资料画面——论证密度全部由台词承担。
4. **冷开场摘要段前置组装**：把讲稿结论压成 30.73 秒摘要段（5 句）置于片头快切（11 个镜头、中位约 2.7 秒），以黑场叠化（00:00:30.32）与正文分隔；正文从自我介绍重开，总论句在正文中段原样复现回锚。
5. **字幕与包装**：句级硬字幕整句上字；角标集名打字入场替代独立字卡；姓名条（姓名＋平台号＋机构职务）与财经免责声明小字常驻；包装层清单见 effects.json。
6. **声音处理**：全片无 ≥0.8 秒无声停顿（silencedetect -50dB/0.8s 计数 0），句间以语流与底噪连续衔接；整体响度 −14.08 LUFS、LRA 4.60 LU，真峰值 +1.59 dBTP 已越 0 dBTP——响度达标但动态平直、峰值留有削波风险，属本片声音侧的实测短板。
7. **发布与数据登记**：抖音发布，标题《机器人的投资逻辑》，简介即内容摘要；截至 2026-11-21 本批全量排名口径点赞 1,616、全量第 123 位——为本批已蒸条目中数据最低者之一，与 VID006（张维迎，点赞未登记于本表外）的学者型长讲形成对照：投资人讲产业的本题材在本账号的点赞表现弱于学者讲义型内容（相关性观察，非因果结论）。

## 工具链（复原）

- 拍摄：多机位现场录制系统（机位构成由成片反推）。
- 剪辑：机位轮换跳切＋一处黑场叠化；字幕整句上字。
- 包装：角标/姓名条/免责小字/片尾字卡模板（太学节目包装系统）。
- 本次蒸馏分析工具：ffprobe/ffmpeg 8.1.2（元数据、响度、静音、场景分数、抽帧）、faster-whisper small（词级对齐，经 stage1b 绕行）、Python 标准库＋PIL（定阈、接触表、生成）。
