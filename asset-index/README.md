# Unified AI Asset Index

Shared, tool-neutral asset metadata for AI assistants. Read schema.json and assets.jsonl. Each JSONL line is one asset. Search by type, tags, style, use_cases and verification_status. Never assume discovered assets are licensed or reproducible.

This public index must not include personal writing, secrets, tokens or private repository contents. Rendering requires separate video tools. AI clients need explicit GitHub read access or the public raw URL; this index does not automatically connect them.
